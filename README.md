# 🎮 Sliding Puzzle

A fun and interactive sliding puzzle game built with **React**, **TypeScript**, **SASS**, and **Framer Motion**.

## 🧩 Overview

This project is a classic sliding puzzle where tiles must be arranged in the correct order by moving them into the empty space. It features:

- A responsive layout
- Smooth animations with Framer Motion
- Clear game logic and win detection
- Playful and modern styling using SASS

## 🚀 Tech Stack

- **React** (with Vite)
- **TypeScript**
- **SASS** (Modular styling)
- **Framer Motion** (for animations)
